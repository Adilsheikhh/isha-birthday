# 🎂 Happy Birthday, Isha!

A little one-page surprise made with love — animated balloons, a photo wall, a heartfelt letter,
flip cards, a blow-the-candles cake, confetti and a synthesized "Happy Birthday" tune.

Built as a static site (plain HTML/CSS/JS) so it deploys anywhere with zero build step.

## Features
- Envelope "open" intro
- Animated gradient hero with floating balloons + sparkles
- Polaroid masonry photo gallery with lightbox
- Handwritten letter section
- Six "reasons you're amazing" flip cards
- Interactive birthday cake — tap the candles to blow them out
- Confetti bursts + cursor sparkle trail
- "Happy Birthday" melody via the Web Audio API

## Run locally
Just open `index.html`, or serve it:

```bash
python3 -m http.server 8000
```

## Deploy
Deployed on Vercel as a static site (no configuration needed).
